# october-harness

October's coding-agent fork of [pi](https://github.com/earendil-works/pi) (MIT). The published CLI is [`@october-dev/october`](packages/coding-agent).

```bash
npm install -g --ignore-scripts @october-dev/october
october login
```

- Docs: [https://www.october.dev](https://www.october.dev)
- Package README: [packages/coding-agent/README.md](packages/coding-agent/README.md)
- Fork notes and verified interface: [OCTOBER.md](OCTOBER.md)

This monorepo still contains the upstream workspace packages (`pi-ai`, `pi-tui`, …) that the CLI depends on. October does **not** publish `@earendil-works/pi-coding-agent`.
